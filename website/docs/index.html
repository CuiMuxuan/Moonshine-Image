02

先记住这一条工作逻辑

图片和视频的具体操作不同，但最终都围绕同一条目标链。每一段都可以按素材和任务自由选择、重复或跳过。

上传处理源 → 制作 / 组合蒙版 → 调用模型处理 → 预览 / 编辑 → 导出新结果
这不是固定的线性向导。 “智能选区”和“手动绘制蒙版”可以二选一，也可以叠加；OCR、SAM、手绘和擦除都会产生或修改同一张最终蒙版。
