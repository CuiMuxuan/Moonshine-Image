02

先记住这一条工作逻辑

图片和视频的具体操作不同，但最终都围绕同一条目标链。每一段都可以按素材和任务自由选择、重复或跳过。

手绘 / 擦除OCR / SAM 选区
组合蒙版预览 · 编辑 · 撤销
模型处理检查结果 · 导出新文件
这不是固定的线性向导。 “智能选区”和“手动绘制蒙版”可以二选一，也可以叠加；OCR、SAM、手绘和擦除都会产生或修改同一张最终蒙版。

03

运行要求与使用边界

支持平台Windows x64
处理位置本地运行，原文件不覆盖
默认输出输入文件旁的 Moonshine-Output

模型、运行环境和部分加速能力取决于当前机器与已安装资源。应用会在能力不可用时说明原因，基础功能不会因为可选模型缺失而消失。
