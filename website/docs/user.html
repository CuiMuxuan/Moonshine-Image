使用说明 / 从开始到结果

每一步都由你决定，结果交给本地模型。

Moonshine-Image 把图片和视频的处理工具放在同一个工作逻辑里：先准备处理源，再做出蒙版，调用适合的模型，检查结果并导出一份新文件。

01

开始使用

首发平台是 Windows x64。你可以选择安装包，也可以使用免安装包；两条入口在首次启动时都会检查同一套本地运行环境。

入口 A

安装包

  1. 下载 Windows x64 安装包并运行安装程序。
  2. 选择安装位置，完成安装后从开始菜单或桌面启动。
  3. 首次启动进入环境检查和模型准备。

入口 B

免安装包

  1. 下载压缩包并解压到有写入权限的目录。
  2. 双击启动 Moonshine-Image；不需要注册系统安装项。
  3. 首次启动进入同样的环境检查和模型准备。

首次启动会发生什么

  • 检查运行环境：确认 Python、FFmpeg、Torch 和本地后端是否就绪。
  • 选择环境规格：按提示选择 auto、CPU 或 CUDA；实际可用能力取决于机器和驱动。
  • 准备模型：缺少的资源进入下载或手动导入流程；模型不可用时，界面会说明原因。
  • 保护已有环境：准备失败会保留旧的 active 环境，并提供回滚路径。
  • 开始前确认：检查后端状态、模型状态和输出目录，再导入第一份素材。
两种版本使用同一套准备流程。如果运行环境或模型尚未就绪，请按界面提示打开“服务管理”或“模型管理”；准备完成后再返回工作台。

02

统一工作逻辑：不是线性向导

“图片”和“视频”使用不同的编辑器和时间轴，但处理本质一致。每一步都可以重复、跳过或回到前面修改。

上传处理源 → 制作 / 组合蒙版 → 调用模型处理 → 预览 / 编辑 → 导出新结果
可选

智能选区和手动绘制蒙版可以二选一。

可叠加

OCR、SAM、手绘和擦除可以叠加到同一张最终蒙版。

可回退

在预览、写回、编辑、擦除、撤销 / 重做和确认之间来回调整。

03

图片处理

A

导入处理源

点击顶部“选择文件”导入当前图片，也可以选中多张图片或一个文件夹。拖放文件到工作区同样会触发导入。

B

建立或组合蒙版

在“蒙版模式”选择手动绘制或智能选区。可使用笔刷、矩形、橡皮擦，也可从“OCR 文本智能选区”、SAM 点选 / 框选或“文本智选”开始。

C

预览并确认蒙版

打开“候选蒙版”勾选结果，再用“撤回”“重做”“清空智能选区结果”继续调整；确认覆盖范围后再运行模型。

D

调用模型并导出

在设置面板选择可用模型和作用范围，点击“运行模型”；用“对比原图”检查效果，最后点击“下载”导出。

智能选区的细节

OCR

RapidOCR 会把文字区域变成候选蒙版。默认高置信度结果直接选中，中等置信度结果保留为候选；可在“智能选区设置”里调整“直接选中阈值”“候选阈值”，也可开启“使用 SAM 增强文本蒙版”。

SAM

点选、框选和文本智选能力取决于当前安装的模型。界面会隐藏不可用操作；SAM2.1 可用于视频传播，标准 SAM3 可支持文本智选，SAM3.1 Multiplex 当前只用于图片文本提示。

04

视频处理

导入视频拆帧并建立时间轴
→
手动轨道绘制或导入蒙版轨道
智能传播SAM2.1 / SAM3 与关键帧编辑
水印轨道SLBR track plan 按活动帧执行
→
预览 / 试跑确认范围和效果
→
处理并导出WebAV 失败时回退 FFmpeg
  • 在时间轴中定位要处理的时间段，维护 currentTime、处理范围和可恢复快照。
  • 蒙版轨道可以由手绘、智能传播或 SLBR 计划提供；非活动帧会跳过相应处理。
  • 先运行预览试跑，再处理完整区间。视频流程独立于图片批处理，不是图片队列的简单延伸。
  • WebAV 导出失败时使用 FFmpeg fallback；完成后合并并确认结果。

05

模型与限制

Moonshine-Image 模型用途与条件
模型 / 能力适合处理使用前提与边界
LaMa通用图像擦除基础模型；在 MAT 不可用时可作为回退。
MAT蒙版修复需要 CUDA；受 CC BY-NC 4.0 非商业许可限制。CPU 不可用时会提示并回退 LaMa。
SLBR可见半透明水印，图片或视频轨道支持全图或显式局部 mask / tile 规划；不承诺恢复被完全遮挡的真实细节。
SAM1 / SAM2.1 / SAM3点、框、文本提示和视频传播能力以当前模型 metadata 为准，不按文件名猜测；sam3_1_multiplex.pt 不宣传图像点选或框选。
看到“条件可用”时先查看应用中的后端、模型和运行环境状态。缺失 CUDA、权重或 provider 时，能力会被隐藏或给出回退提示，不代表所有机器都能运行全部模型。

06

结果与文件

Moonshine-Image 默认把结果写到输入文件旁的 Moonshine-Output 目录，并创建新文件。原始文件不会被覆盖。

处理结果主预览中检查，再导出新文件
批处理逐项报告成功 / 失败，可取消
视频导出分段处理，合并后确认
源文件只读使用，不会被覆盖

如果输出目录或模型状态异常，先处理应用提示，再重新运行对应任务；不要把未完成的临时文件当作最终结果。
