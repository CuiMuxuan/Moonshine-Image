GOOD TO KNOW / 常见问题

开始之前，
你可能想知道。

打开文档中心
没有 NVIDIA 显卡，可以使用吗？

可以选择 CPU 运行环境，并使用当前环境支持的模型。MAT 需要 CUDA，其他模型的可用条件以应用中的能力提示为准；处理速度取决于设备、素材与模型。

图片和视频会上传到云端吗？

图片与视频的模型处理在本机执行。首次准备运行环境、下载模型或检查更新时可能需要联网，本地处理不等于应用完全没有网络请求。

处理结果会覆盖原始文件吗？

不会。应用创建新结果，默认输出到输入文件旁的 Moonshine-Output 目录。你可以先预览结果，再决定是否使用。

下载后就能完全离线使用吗？

常规安装包与免安装包都是应用本体。需要先准备兼容的运行环境和模型；离线准备方式请按使用指南和对应发布说明操作。

所有模型都能用于商业用途吗？

不能一概而论。项目代码与各模型遵循各自许可，MAT 受 CC BY-NC 4.0 非商业许可约束。处理素材前，也请确认你拥有相应的使用和修改权利。

如何连接 AI 客户端？

在应用中配置本地 MCP，并按照接入文档设置客户端。调用受工具、目录和确认策略约束，具体能力还取决于服务和模型是否就绪。阅读 MCP 接入文档。
